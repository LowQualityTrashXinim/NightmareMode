# NightmareMode

Drastically increased Terraria difficulty.
This is a fork of the main Mod using Everlasting as the Core of the mod.

This mod was made for 2 purposes :
- Create a mod that drastically increase Terraria difficulty.
- Demonstrate the powerful Everlasting Core capabilities to create branches of mini mod.
